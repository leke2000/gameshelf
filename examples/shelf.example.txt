# Example GameShelf manifest.
#
# Format:  category|name|target|note
#   category  folder name the entry appears under on the shelf
#   name      label shown on the shelf (need not match the folder on disk)
#   target    the real install folder - this is what must never be moved
#   note      free text, appears in CATALOG.md
#
# Lines starting with '#' and blank lines are ignored.
# Save as UTF-8. A .csv with columns category,name,target,note works too.

# --- hand-picked, clean names ---
Action|Hollow Knight|G:\Hollow.Knight|includes save editor
Action|Elden Ring|D:\SteamLibrary\steamapps\common\ELDEN RING|
RPG|Cyberpunk 2077|H:\@game\Cyberpunk 2077|

# The shelf label does not have to match the folder name, which is the whole
# point when the real folder is a serial number or a string of mojibake.
